# Spec · Perfil Vendas e associação de usuários (T1)

Pedido do fundador (13/11/2026): "Criar 1 novo perfil, um para vendas que só vê menu vendas e permitir associar este perfil a usuários existentes."

## Escopo
- Botão "+ Perfil Vendas" em Acesso → Perfis: cria (ou atualiza) o perfil "Vendas" com as telas do menu "S7 · Vendas Ativo" (Inside Sales opcional).
- Botão "👥 Associar usuários" em cada perfil (não admin): marcar usuários existentes que passam a usar o perfil.

## Critérios de aceite
- Perfil Vendas só com as telas do menu Vendas; usuário associado vê só esse menu no próximo login/recarga.
- O administrador logado não aparece na lista (não perde o próprio acesso).
